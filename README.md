# ESP32 WiFi 인원 센싱 시스템 (아이디어 단계)

> 별도 송신기 없이 **기존 공공 WiFi 신호**와 **ESP32 수신기**만으로 실내 인원 밀집도를 추정하는 시스템
> 학술동아리 아이디어세미나 발표 (2026.11)

## 문제

콘서트장, 경기장처럼 사람이 몰리는 실내 공간에서는 특정 출입구에 인원이 쏠리면서 압사 사고 위험이 커집니다.
카메라는 사각지대와 사생활 문제가 있고, 별도 센서망을 까는 것은 비용이 큽니다.

## 아이디어

- 사람의 몸은 WiFi 신호를 흡수하고 반사하기 때문에, 인원이 많아질수록 수신 신호가 달라집니다.
- 이미 설치된 **공공 WiFi를 송신기로 그대로 활용**하고, 구역마다 저렴한 **ESP32 수신기**만 배치합니다.
- 구역별 밀집도를 추정해 **붐비는 출입구의 인원을 한산한 출입구로 분산 안내**합니다.

~~~
공공 WiFi AP ──신호──▶ [사람들] ──▶ ESP32 수신기 (구역별)
                                         │
                                         ▼
                              밀집도 추정 ──▶ 출입구별 유동 배분 안내
~~~

## 활용 예시

- 콘서트, 스포츠 경기 등 실내 대형 행사장의 압사 예방
- 밀집도에 따른 출입구 인원 유동 배분
